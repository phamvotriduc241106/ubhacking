# Running and deployment

## Local setup

From the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
python scripts/download_models.py
cp .env.example .env
```

Edit `.env` privately and set `GEMINI_API_KEY` to a valid Gemini API key. Do not put keys into frontend code or commit them. The backend reads process environment variables and the root `.env`; existing process variables take precedence. To use the optional USB serial feed, set `FOLLAND_SERIAL_PORT` to the detected device path. Do not guess hardware wiring; see the original proposal.

Gemini vision uses up to two attempts with a 40-second per-attempt timeout and a 65-second total request budget by default. Set `GEMINI_VISION_TIMEOUT_SECONDS` (1–60), `GEMINI_VISION_TOTAL_TIMEOUT_SECONDS` (1–90), and `GEMINI_VISION_MAX_ATTEMPTS` (1–3) in the backend environment to change these limits. Invalid values use defaults. SDK retries are disabled for vision; only timeouts, rate limits, and selected server errors are retried within the total budget. A separate report call can take up to 25 seconds after vision. Logs record the attempt, elapsed time, outcome and safe HTTP error code, without the key, image, prompt, or provider error text. A `timeout` means the vision deadline expired; it does not establish the provider-side cause. The endpoint retains its deterministic fallback when Gemini is unavailable.

Start the backend:

```bash
uvicorn backend.app:app --host 0.0.0.0 --port 8000
```

Start the frontend in a second terminal:

```bash
cd frontend
npm ci
npm run dev -- --host 0.0.0.0 --port 5173
```

Open `http://localhost:5173`. If port 8000 is already in use by another app, start this backend on another port and set `VITE_BACKEND_URL` when starting Vite. For example, with the backend on 8001:

```bash
VITE_BACKEND_URL=http://127.0.0.1:8001 npm run dev -- --host 0.0.0.0 --port 5174
```

Upload a tomato JPEG or PNG and select **See my plant check**. The report says **Gemini** when generated by Gemini, or **automatic fallback** with a safe failure category when the key is missing, rejected, rate-limited or the service fails. Air readings default to simulated unless serial data is configured; manually entered values are labeled user-reported. The screenshot/photo is sent to Google when Gemini is enabled.

API request example, with a locally saved photo:

```bash
curl -X POST http://localhost:8000/api/analyze \\
  -F image=@tomato.jpg -F crop=tomato -F soil_condition=unknown \\
  -F manual_temperature_c=24 -F manual_humidity_pct=60
```

The JSON response contains `detector`, `gemini_observation`, `sensor_data`, `harvest`, `watering`, `fertilizer`, `data_sources`, and `report`. The API key is not part of the request or response.

## Container deployment preparation

A Dockerfile is provided for a single-origin build: the backend serves the built frontend and `/api`, and downloads the pinned pretrained weights while building. This avoids exposing a backend secret to the browser and avoids hardcoded production API URLs.

```bash
docker build -t folland .
docker run --rm -p 8000:8000 --env-file .env folland
```

Open `http://localhost:8000`. In a hosting provider, configure `GEMINI_API_KEY` as a server-side environment secret instead of uploading `.env`. This Dockerfile has **not been built or deployed in this environment**. The model and Python dependencies make the container large and may exceed small/free serverless limits. Vercel supports Python functions, but this combined ML workload has not been validated against its package, memory or execution limits; do not assume the container is Vercel-ready.

Before public deployment, put the service behind HTTPS with authentication, a distributed or edge rate limiter and request-body limits, and verify privacy, retention, licensing and costs. The built-in rate limit is process-local and does not protect multiple workers or instances. No physical serial device is available in ordinary cloud hosting. No paid service has been enabled or deployed.

## Troubleshooting

- `not_configured`: set `GEMINI_API_KEY` server-side and restart the backend.
- `authentication_failed`: check the key, project and API access in Google AI Studio. Replace any exposed key. Free-tier status alone does not validate a key.
- `quota_exceeded`: check the project's quota and wait or adjust usage.
- `timeout` / `unavailable`: check service connectivity and retry. A deterministic report is still returned.
- Missing detector: run `python scripts/download_models.py`. It downloads the publisher's AGPL-3.0 weights; review [model validation and licensing](model-validation.md).
- Invalid image: use JPEG/PNG within 15 MB and 25 megapixels; HEIC depends on decoder support.
- A simulated reading is expected unless serial is configured and fresh. Air humidity is not soil moisture; distance alone is not plant height.
